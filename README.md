# 칩테이블

카드는 있는데 칩이 없을 때, 친구들이 각자 휴대폰으로 칩을 나눠 갖고 베팅하는 놀이용 포커 칩 테이블입니다.
칩은 놀이용 점수이며 실제 돈과 연결되는 기능은 없습니다.

## 쓰는 법

1. 호스트가 **테이블 만들기**에서 인원, 시작 칩, 블라인드를 정합니다.
2. **초대 링크**를 눌러 친구들에게 보냅니다. 링크로 들어오면 코드가 미리 채워져 있어 이름만 넣으면 됩니다.
3. 호스트가 **선 정하고 시작**을 누르면 선부터 차례대로 베팅이 진행됩니다.

휴대폰 하나로만 칠 때는 **한 기기로 하기**를 쓰세요.

## 구성

- `index.html` 한 파일로 동작합니다 (GitHub Pages로 배포).
- 기기 간 실시간 연결은 Supabase Realtime의 broadcast·presence 채널을 씁니다. 데이터베이스 테이블은 쓰지 않습니다.
- 호스트 기기가 게임 상태를 가지고, 플레이어는 요청만 보냅니다. 호스트가 검증한 상태가 모두에게 전달됩니다.
